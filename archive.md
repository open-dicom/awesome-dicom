# Archive

Projects that used to be listed in [Awesome DICOM](readme.md) but are archived, deprecated or no longer maintained. They are kept here for reference.

A project moves here when its repository is archived or deprecated, or when its default branch has had no commits for about two years. Widely used projects that are stable rather than abandoned stay in the list. If a project here becomes active again, open a pull request to move it back.
